# 界面截图

用真实客户端代码在 Chromium 中渲染，数据为合成演示数据，不含真实客户或邮件。宽度 1440px，`14-dark` 为深色主题，`15-english` 为英文界面，`16-narrow` 为 900px 宽度。

`17-wechat-decide` 微信事项的审核（建议回复、对话、右侧聊天记录），`18-wechat-chats` 全部事项按会话阅读，`19-wechat-settings` 设置中的联系人与群聊名单，`20-wechat-dark` 深色主题下的群聊。

`21-ai-suggest` AI 把握不足时在“待我决策”里建议方案，`22-rule-matching` 方案的匹配方式、适用说明和 AI 学到的例子。
